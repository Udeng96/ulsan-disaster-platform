# server

장비 상태 수집과 판정의 원본 소스에서 운영자료를 제외한 코드입니다.

원본 설정·DB 시드·시설 데이터·배포 스크립트·Git 이력·벤더 바이너리를 포함하지 않습니다.

## 구성 범위

src/에는 수집·변환·조회·상태 처리 코드와 기존 단위 테스트를 담았습니다.
실행 설정은 application.example.yml을 참고해 별도로 구성합니다.
실제 업무 DB 스키마·데이터는 제공하지 않으며 기본 배포용 실행 구성을 포함하지 않습니다.
Java 17과 해당 빌드 도구가 필요합니다. 서비스 전체 기동보다 코드·단위 기능 검토를 위한 구성입니다.
