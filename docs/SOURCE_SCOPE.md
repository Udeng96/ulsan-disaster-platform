# 코드 구성 범위

modules/의 9개 업무 모듈은 원본에서 선별·정리한 소스를 포함합니다. oms와 crypt는 기존 공통 제품의 원본 대신 연계 설명을 제공합니다.

운영 설정과 배포 스크립트, 실제 DB 시드, 벤더 JAR, 원본 화면 이미지, 과거 Git 이력을 제외했습니다. 원본 패키지와 코드 구조는 검토를 위해 유지했습니다.

dashboard의 mock 데이터는 가상 레코드로 새로 만들었으며 이미지는 단순 대체 이미지입니다. 벤더에 의존하는 owl 상세 조회는 별도 구현이 필요한 경계로 바꿨습니다.

Java 서비스는 원본 업무 DB 없이 전체 기능을 재현하는 실행 패키지가 아닙니다. 기존 데이터와 외부 연계가 필요한 부분은 서비스별 README를 참고하세요.

이 디렉토리에 새 라이선스를 부여하지 않았습니다. 원본 코드와 제3자 자산의 재배포 조건을 그대로 대체하지 않습니다.
